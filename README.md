# Proyecto Web - Revista Literaria
Sitio web personal y revista literaria desarrollado con HTML5, Bootstrap 5 y arquitectura SCSS (Sass).
---
## 🛠️ Tecnologías utilizadas
- **HTML5:** Estructura semántica.
- **CSS3 / SCSS (Sass):** Estilos modulares, variables, mixins, anidamiento y enfoque mobile-first.
- **Bootstrap 5:** Sistema de grillas, carrusel, modales y utilidades responsivas.
- **Node.js / npm:** Gestión del compilador de Sass.
- **Git & GitHub:** Control de versiones y despliegue continuo.
